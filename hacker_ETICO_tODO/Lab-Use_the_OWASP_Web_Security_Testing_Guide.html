Incompleto Práctica de Laboratorio - Usar la Guía de Pruebas de Seguridad Web de OWASP

Objetivos

En esta práctica de laboratorio se cumplirán los siguientes objetivos:

  • Parte 1: Investigar la Guía de Pruebas de Seguridad Web (WSTG) de OWASP
  • Parte 2: Escanear un sitio web e investigar las referencias a vulnerabilidades

Trasfondo / Escenario

La fundación sin fines de lucro Proyecto Abierto de Seguridad de Aplicaciones a Nivel Mundial (Open Worldwide Application Security Project OWASP) desarrolló la Guía de Pruebas de Seguridad Web (WSTG) para probar los problemas de seguridad más comunes de las aplicaciones web. La guía es útil para diversas partes interesadas, como desarrolladores, evaluadores de software, especialistas en seguridad y gerentes de proyectos. La Guía de Pruebas de Seguridad Web de OWASP es una herramienta gratuita que está disponible para organizaciones e individuos.

La guía de pruebas también es una herramienta útil para la piratería ética. Los hackers éticos pueden usar la guía para probar las aplicaciones web en ejecución de sus clientes en busca de vulnerabilidades de seguridad comunes.

En esta práctica de laboratorio, revisará el WSTG y luego escaneará una aplicación web en busca de vulnerabilidades con el proxy de ataque Zed (ZAP) de OWASP. Investigará algunas de las vulnerabilidades que se descubrieron y remitirá una al WSTG.

Recursos necesarios

  • Maquina Virtual Kali (Kali VM) personalizada para el curso de Pirata Ético
  • Acceso a Internet

Parte 2: Escanear un sitio web e investigar las referencias a vulnerabilidades

En esta parte de la práctica de laboratorio, realizará un análisis de vulnerabilidades con Zed Attack Proxy (ZAP). Su objetivo es un sitio web intencionalmente vulnerable que está disponible en su VM. Luego utilizará WSTG para obtener más información sobre una vulnerabilidad que descubrió.

Paso 1: Abra ZAP e inicie un escaneo.

  1. Inicie la VM de Kali según sea necesario. Navegue hasta el menú de Kali. Busque zap e inicie el escáner OWASP Zap.
  2. Haga clic en el botón de opción superior para mantener la sesión. Esto significa que puede volver a la sesión más tarde.
  3. Cierre la ventana de diálogo Manage Add-ons (Administrar complementos).
  4. En la ventana principal de ZAP, haga clic en Automated Scan para iniciar un escaneo.
  5. En el campo URL to Attack, ingrese 172.17.0.2/dvwa.
  6. Haga clic en el botón Atacar para comenzar el escaneo. El análisis tardará menos de 10 minutos en completarse.

Primero, ZAP utiliza un rastreador web (web spider) para explorar la URL e identificar los recursos que están disponibles allí. Luego aplicará análisis de vulnerabilidades a cada recurso.

Paso 2: Investigue los resultados.

  1. Seleccione la pestaña Alerts si aún no está seleccionada. Cuando finalice el escaneo, serás trasladado automáticamente allí.

  1. Desplácese hacia abajo hasta la sección Etiquetas de Alerta de la vulnerabilidad. Anote la clave y el valor de WSTG. Haga clic en el valor y use las teclas Ctrl-C para copiar la URL en el portapapeles.
  2. Abra un navegador y pegue la URL en el campo de URL. Navegue hasta el sitio de WSTG y lea sobre la vulnerabilidad y los métodos de prueba. Revise esta información sobre la vulnerabilidad para comprender lo que WSTG ofrece al evaluador de penetración.

Preguntas de reflexión
1. ¿De qué manera la Guía de Pruebas de Seguridad Web de OWASP puede ayudar a las organizaciones a proteger sus aplicaciones?
Área de Respuesta
Las respuestas variarán, pero pueden incluir: identificar los pasos para crear y operar un programa de pruebas de aplicaciones web, determinar las brechas entre las prácticas existentes y las mejores prácticas de la industria, garantizar que el software esté codificado de manera segura y eficiente, tomar decisiones informadas y sobre qué actividades y herramientas de seguridad invertir.
2. Al realizar una prueba de penetración de las aplicaciones web de un cliente, ¿cómo podría utilizar el WSTG como guía?
Área de Respuesta
El WSTG ofrece pautas para 10 tipos de pruebas que podrían realizarse en una prueba de penetración. Cada tipo de prueba tiene una serie de pruebas específicas con explicaciones, instrucciones y ejemplos para usarlas, incluidas listas de herramientas útiles.
